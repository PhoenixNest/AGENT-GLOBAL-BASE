## Final Design

- **Origin.** `_prompt_origin.py` `extract_user_text()` removes complete, recognised harness envelopes from the start of a prompt: the task-notification envelope, the sub-agent hand-back envelope (opening line, `<agent-message>` element closed at column zero, fixed trailing paragraph), the local-command elements, each optionally inside one `<system-reminder>` wrapper whose opening tag may carry attributes. Only envelopes are removed; user words are never hidden. Origin is `notice` (nothing left; the hook passes), `mixed` (user text left; each hook evaluates that text only) or `user` (nothing removed). An envelope after the user's words, or an incomplete one, stays in the text and is evaluated.
- **H-P03.** Prose only (URLs, fenced code and `>` quote lines removed; inline code keeps its words and loses its backticks), one sentence at a time, whole words, P0 and P1 case-insensitive. Matching time is linear in the prompt length: the lead-in prefix (at most 80 characters) is checked word by word against a fixed set, and every pattern has bounded or non-overlapping repetition. `test_matching_is_fast_on_adversarial_input` holds the bound. Auto-advance accepts fused and hyphen-less forms; force-push accepts a suffix on "force" and up to two words before "push". Strong tier (block, original message text): a base-form verb that opens its clause after optional lead-ins, with no negation preceding it or inside the verb phrase; negation after the object does not soften. Weak tier (warning in additionalContext, no block): co-occurrence without that shape, negation before or inside the verb phrase, a non-base verb form, or a generic object.
- **H-P02.** A hint requires Company pipeline work (Company path or pipeline name, or an explicit "Stage N" with a Company term); a lab-system prompt needs the path or pipeline name itself. Recruitment and Studio subjects stay suppressed.
- **H-P01.** Scoring and the confirmation flow are unchanged and run on the user's text only.
- **Command arguments.** The content of a `<command-args>` element is what the user typed after a slash command; only its tags are removed and the content is evaluated as user text.
- **Self-override.** A user who types a complete, well-formed envelope at the very start of a prompt hides the text inside it from the hooks. This is deliberate: only the user types prompts, so the user is overriding their own checks.
- **Audit.** Each call-history row records origin (`user`, `mixed`, `notice`), tier, rule id and matched keywords drawn from a fixed vocabulary, never the prompt text or captured words. An unforeseen error in H-P03 is logged as decision `error` with the exception type name only, and the hook exits 0.
