## 1. Findings and corrections

| Finding                                           | Correction                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F1 (P1, veto) — exponential backtracking          | A hook timeout lets a message through unchecked, so this was a bypass. The lead-in prefix is now checked word by word against a fixed set of words and phrases, in linear time, with no regular expression. A prefix over 80 characters is not an instruction shape. The clause-start search looks back over a bounded window. The other patterns were audited: fence, clause-separator, sentence-split, quote, URL and envelope patterns have bounded or non-overlapping repetition and anchored starts. `test_matching_is_fast_on_adversarial_input` runs `extract_user_text()` and `scan()` on eleven adversarial shapes at n=40 (including the early-closed agent-message shape) and requires each under 100 ms |
| F2 (P2) — `command-args` removed with its content | Only the `<command-args>` tags are removed; the content is kept and evaluated as user text                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| F3 (P2) — inline code hid terms                   | Inline code keeps its words and loses only its backticks. Fenced blocks, `>` quote lines and URLs stay removed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| F4 (P3) — verb patterns too narrow                | Auto-advance accepts the fused and hyphen-less forms. Force-push accepts a suffix on "force" and up to two words before "push". Both are written without nested repetition                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| F5 (P3) — keywords held captured text             | Logged keywords come from a fixed vocabulary (`KEYWORD_VOCABULARY`), one canonical term per matched group                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| F6 (P3) — silent outer exception handler          | The handler writes a row with decision `error` and the exception type name only, and still exits 0                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| F7 (accepted) — fake envelope at the start        | Documented, not changed: a user who types a complete envelope at the very start of a prompt hides their own text from the hooks. This is a deliberate self-override; only the user types prompts                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
