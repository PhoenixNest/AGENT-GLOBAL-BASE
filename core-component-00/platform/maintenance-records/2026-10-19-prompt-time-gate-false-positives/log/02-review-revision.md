## 1. Findings and corrections

| Finding                                    | Correction in the final design                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| F1 — agent hand-backs not recognised       | The session transcript was searched for the envelope shapes. A hand-back is the line `Another Claude session sent a message:` (or `... while you were working:`), an `<agent-message from="...">` element, and a fixed paragraph beginning `That "other Claude session" is an agent working inside this same session`. A wrapper may carry attributes: `<system-reminder id="...">`. `_prompt_origin.py` recognises all of these, plus the task-notification and local-command envelopes. The harness indents every report line, so the `</agent-message>` closing tag stands at column zero and is matched there |
| F2 — mixed submissions bypassed            | `prompt_origin()` is replaced by `extract_user_text()`. It removes only complete, recognised envelopes from the start of the prompt (each with its optional wrapper and trailing paragraph) and returns the rest. Nothing left: origin `notice`, pass. Text left: origin `mixed`, and each hook evaluates only that text (H-P03 scans it, H-P01 scores it, H-P02 checks it). An envelope after the user's words, or one that is not complete, is not removed. Log rows record `user`, `mixed` or `notice`                                                                                                         |
| F3 — negation scope too wide               | Negation now softens a match only when it ends the preceding clause or sits between the verb and the end of the matched span. Negation after the object does not soften. Strong also requires a base-form verb, so a description such as a gerund subject ("... is prohibited") stays weak without relying on trailing negation                                                                                                                                                                                                                                                                                   |
| F4 — lowercase p0 and p1 no longer matched | P0 and P1 match case-insensitively as whole words. The identifier case stays clean because there is no word boundary before "p1" in `mchlp1168`; a test holds it                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
